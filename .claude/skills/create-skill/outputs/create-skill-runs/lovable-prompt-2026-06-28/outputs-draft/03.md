```
## Context
A B2C personal training platform for online fitness coaches and their clients. Clients log in to view their weekly workout plan, mark exercises as completed, and send messages to their trainer. Monthly subscription model — no self-serve registration.

## Stack
- Framework: React + TypeScript + Vite
- Styling: Tailwind CSS + shadcn/ui (components only — no other component library)
- Backend: Supabase
  - Auth: Supabase Auth (email + password)
  - Database: PostgreSQL via Supabase
  - Storage: none
  - Edge Functions: no
- Additional packages: react-hook-form, zod

## Design System
- Component library: shadcn/ui
- Color palette: background #1A1A2E, accent #E94560, text and neutrals from shadcn/ui default tokens
- Typography: shadcn/ui default (Inter)
- Tone: energetic, professional, fitness-focused
- Dark mode: yes

## Scope — Build exactly these features
1. Client login screen (Supabase Auth, email + password)
2. Weekly workout view — exercises grouped by day (exercise name, sets, reps, rest time)
3. Mark exercise as done — toggle per exercise, state persisted in database
4. Messaging screen — client sends text messages to trainer; trainer can reply
5. Trainer admin panel — list of all clients, access to each client's workout plan

## Out of v1 — Do not build
- Payment processing or subscription management
- Exercise video library or video playback
- Progress tracking, analytics, or performance reports
- Client self-registration flow

## Security Constraints
- Authentication: required — Supabase Auth (email + password)
- Row-level security:
  - workout_plans: clients read only their own plan; trainer reads all
  - messages: each party reads their own thread; trainer reads all threads
- Input validation: zod on all forms (login, message compose)
- Sensitive data: none beyond email in auth.users (Supabase-managed)

## DO NOT
- DO NOT add any feature not listed in Scope.
- DO NOT use any component library other than shadcn/ui.
- DO NOT generate placeholder content, lorem ipsum, or stub data.
- DO NOT add analytics, telemetry, or tracking scripts.
- DO NOT install packages not listed in the Stack section.
- DO NOT add client self-registration — trainer creates client accounts in Supabase directly.
- DO NOT add video playback or exercise media — this is v2.
```
