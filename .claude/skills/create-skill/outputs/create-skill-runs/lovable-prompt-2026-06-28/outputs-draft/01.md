Para criar um prompt em inglês para o Lovable que bloqueie escopo, stack, design e segurança desde o início, preciso de algumas informações:

1. **Problema** — Qual dor esse app resolve? Quem sente essa dor?
2. **Usuários** — Quem faz login? Time interno, clientes B2B, ou usuários B2C?
3. **Escopo v1** — O que precisa funcionar na v1? O que fica explicitamente fora?
4. **Stack** — Vai usar Supabase? Qual provedor de autenticação? Pagamentos? APIs externas?
5. **Design** — Tem cores e fontes de marca? Ou usamos o padrão do shadcn/ui?
6. **Integrações** — Algum webhook, API externa ou serviço de terceiros no v1?
