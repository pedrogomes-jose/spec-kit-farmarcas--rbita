Para criar um prompt em inglês para o Lovable que bloqueie escopo, stack, design e segurança desde o início, preciso de 6 informações:

1. **Problema** — Qual dor esse app resolve? Quem sente?
2. **Usuários** — Quem faz login? Time interno, B2B ou B2C?
3. **Escopo v1** — O que entra? O que fica fora? O que o Lovable NUNCA deve adicionar?
4. **Stack** — Supabase? Qual auth? Pagamentos? APIs externas?
5. **Design** — Cores/fontes de marca, ou padrão shadcn/ui?
6. **Integrações** — Webhooks ou serviços externos no v1?

O prompt final terá 7 seções (Context, Stack, Design System, Scope, Out of v1, Security, DO NOT) e será entregue em inglês, pronto para colar no Lovable.
