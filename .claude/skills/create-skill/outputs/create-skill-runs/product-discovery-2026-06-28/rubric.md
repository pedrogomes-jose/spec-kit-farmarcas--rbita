# Rubric — product-discovery

Domain: Synthesis / Conversational coaching (custom criteria)

## Criterion 1: Routing Quality (0–20)
| Score | Anchor |
|-------|--------|
| 18–20 | 650+ char description, 8+ trigger phrases (PT + EN), WHAT+WHEN in first 250, "Do NOT use for" with /pointers, third person |
| 12–17 | Description present, some triggers, missing boundary pointer or WHEN clause |
| 0–11 | No frontmatter, first person, or under 100 chars |

## Criterion 2: Output Specificity (0–20)
| Score | Anchor |
|-------|--------|
| 18–20 | CSD and/or Tree populated exclusively from user's context — specific metrics, specific user quotes, specific team beliefs. No generic examples. |
| 14–17 | Principled-decline path: asks only questions that fill actual gaps, shows current framework state; no fabrication |
| 0–13 | Generic output — CSD items could apply to any product; Tree built from training-data assumptions |

## Criterion 3: Output Format Consistency (0–20)
| Score | Anchor |
|-------|--------|
| 18–20 | Same framework format every run: CSD table with 3-column header, Tree with 🎯/📌/└── hierarchy, Próximos passos section |
| 12–17 | Frameworks present but format varies (sometimes table, sometimes bullets) |
| 0–11 | No consistent structure |

## Criterion 4: Discovery Depth (0–20) [Domain primary]
| Score | Anchor |
|-------|--------|
| 18–20 | CSD has ≥3 items per column from conversation; Tree has ≥3 opportunity spaces each with sub-opportunities; próximos passos derived from doubts/assumptions |
| 14–17 | Principled-decline: asks targeted phase-specific questions, shows state after each phase, moves through phases correctly |
| 0–13 | CSD underpopulated (<3 per column) or Tree flat (no sub-opportunities) or phases skipped |

## Criterion 5: Framework Accuracy (0–20) [Domain secondary]
| Score | Anchor |
|-------|--------|
| 18–20 | CSD correctly separates evidenced facts (Certezas) from team beliefs (Suposições) from unknowns (Dúvidas); Tree maps ONLY user pains/desires (no solutions or features) |
| 14–17 | Mostly correct; 1 item misclassified (e.g., a supposition presented as certainty) |
| 0–13 | Solutions in the Tree; or CSD columns collapsed; or framework definitions violated |
