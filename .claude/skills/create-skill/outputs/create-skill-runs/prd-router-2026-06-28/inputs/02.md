# PRD — HabitTrack

## Problema
Usuários querem acompanhar hábitos diários e visualizar streaks, mas os apps existentes são complexos demais para uso casual.

## Usuários-alvo
Adultos entre 25–40 anos que querem criar rotinas simples sem overhead de configuração.

## MVP
- Cadastro e login com e-mail (Supabase Auth)
- Criação de até 10 hábitos por usuário (título, ícone, cor)
- Check-in diário por hábito (sim/não)
- Visualização de streak atual e histórico dos últimos 30 dias em gráfico de barras
- Página de perfil com total de dias consecutivos e hábitos ativos

## Stack sugerida
React + TypeScript + Tailwind + shadcn/ui + Supabase

## Fora do v1
- Compartilhamento social
- Notificações push
- Integração com wearables

## Segurança
RLS no Supabase garante que usuário veja apenas seus próprios hábitos e check-ins.
