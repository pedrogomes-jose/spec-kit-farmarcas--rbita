# PRD — NotifyHub

## Problema
Plataformas SaaS precisam enviar notificações para os usuários via múltiplos canais (e-mail, SMS, push, Slack, WhatsApp) com controle de preferências, filas de retry e rastreamento de entrega. Hoje cada produto implementa isso do zero.

## Usuários-alvo
Desenvolvedores de produtos SaaS B2B que precisam de uma infraestrutura de notificações confiável via API.

## MVP
- API REST para envio de notificações (POST /notifications)
- Suporte a 4 canais: e-mail (SendGrid), SMS (Twilio), Slack webhook, WhatsApp (Meta API)
- Fila de processamento assíncrono com retry automático (3 tentativas, backoff exponencial)
- Registro de entrega com status (queued, sent, failed, delivered)
- Webhook de retorno para o produto chamador informando status final
- Dashboard admin básico para monitorar volume e taxa de falha por canal

## Stack
Node.js + TypeScript + PostgreSQL + Bull (Redis) + Docker + GitHub Actions para CI/CD

## Fora do v1
- SDK por linguagem
- Templates de notificação
- A/B testing de mensagens

## Segurança
API Key por tenant, rate limiting por tenant, logs de auditoria com IP de origem.
