## Context
An internal customer support tracking tool for CS agents. Agents log in with email, view a dashboard of open support tickets, and manage ticket status.

## Stack
- Framework: React + TypeScript + Vite
- Styling: Tailwind CSS + shadcn/ui (components only)
- Backend: Supabase (Auth: email+password; Database: PostgreSQL)
- Additional packages: react-hook-form, zod

## Security Constraints
- Authentication: required — Supabase Auth (email + password)
- Row-level security: tickets — agents read/update own; admins read all
- Input validation: zod on all forms

## DO NOT
- DO NOT add user registration — admin creates accounts in Supabase
- DO NOT add analytics or tracking scripts
- DO NOT install packages not listed in Stack
