Tenho um PRD de melhoria. Pode implementar?

PRD — Sistema de Flashcards: Modo de Revisão Espaçada

Contexto: O sistema atual de flashcards mostra os cards em ordem aleatória. Usuários intermediários precisam de um sistema de revisão espaçada (spaced repetition) para focar nos cards que erram mais.

Funcionalidades:
- Adicionar campo `next_review_at` (timestamp) e `ease_factor` (float) na tabela flashcards

Regras de negócio:
- Ease factor inicial: 2.5
- Acerto fácil: +0.1 no ease factor, próxima revisão em ease_factor * dias_desde_ultima
- Erro: ease_factor volta a 1.3, próxima revisão em 1 dia
- Ease factor mínimo: 1.3

Stack: Cloudflare Workers (Hono) + React + Cloudflare D1 (SQLite)
